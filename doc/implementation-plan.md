# 중학교 수학 웹앱 구현 계획과 작업 지침

작성일 2026-11-24 (Asia/Seoul)

## 첫 버전 제안

React + TypeScript + Vite로 학습 사이트를 만들고, 자료는 Git에서 관리하는 구조화된 콘텐츠로 빌드에 포함한다. Raspberry Pi에서는 Podman의 웹 서버 컨테이너가 정적 파일을 제공한다. 초기 범위에는 학년·단원 탐색, 정의·정리 검색, 웹 수식, 대표 도형 애니메이션을 포함한다.

| 선택지 | 적용 시점 | 근거 |
| --- | --- | --- |
| 정적 콘텐츠 + Nginx | 첫 버전 | 읽기·검색·도형 조작은 브라우저에서 처리할 수 있다. 서버에서 계정이나 DB를 운영할 필요가 없다. |
| Django + SQLite | 관리자 편집 또는 소규모 로그인·기기 간 학습 기록이 필요할 때 | 하모니카 프로젝트와 유사한 운영 방식으로 관리자 화면과 영속 저장을 도입할 수 있다. DB와 백업은 이미지 밖에 둔다. |
| Django + PostgreSQL | 동시 쓰기나 다중 사용자 운영 요구가 확인될 때 | 실제 데이터 규모와 운영 요구를 확인한 뒤 선택한다. |

북마크나 진도 표시를 추가한다면 초기에는 브라우저의 localStorage로 충분하다. 기기 간 동기화는 서버 도입 시 별도로 설계한다.

## 원본 자료와 검수 범위

[중학교 수학 PDF](중학교_수학_정의와_정리.pdf)는 10쪽이며 중1~중3의 정의 D1–D35와 정리 T1–T49를 담고 있다. 총 84개 항목을 웹 콘텐츠에 매핑한다. T40은 원문의 ‘교과 과정 밖’ 표시를 유지한다.

- 항목에는 ID, 학년, 단원, 유형, 제목, 본문, LaTeX 수식, 원본 쪽, 애니메이션 연결값을 기록한다. 기존 D/T 번호를 링크와 검색에 재사용한다.
- 추출한 본문은 페이지 원본과 대조한다. 위첨자, 근호, 분수, 그림 및 표를 따로 확인한다. T43의 특수각 삼각비는 HTML 표로 제공한다.
- 원문과 교육용 보충 설명의 변경 이력을 남긴다. 예를 들어 T19는 같은 기울기를 가진 서로 다른 두 직선이라는 조건, D23은 각 결과가 같은 가능성을 갖는 유한 표본공간 조건, T33은 합과 곱의 적용 조건을 검수한다.
- 공개 배포를 요청받으면 원문·삽화의 공개 사용 범위를 확인한다.

## 도형과 수식

아래의 라이브러리 조합은 초기 설계안이다. 현재 구현은 안내서의 기준 좌표계, ResizeObserver, 화면 배율 동기화, HTML 오버레이를 적용하고 Canvas 2D, requestAnimationFrame, MathML을 사용한다. 이 세션에서 레지스트리에 연결할 수 없어 브라우저 기본 기능으로 구현했다. 공통 슬라이더로 도형을 조작한다.

[웹 수식 및 인터랙티브 가이드](웹%20수식%20%26%20인터랙티브.md)의 Konva + GSAP + KaTeX 구조를 React에 맞게 적용한다. 원본 예제의 CDN 버전은 참고용으로만 사용하고 호환 버전을 확인해 잠금 파일에 기록한다.

- React-Konva로 기준 좌표계 900 × 506.25의 도형을 그린다. 도형 좌표와 계산을 렌더링 코드에서 분리하고, SVG 도형이 필요한 장면은 검토한 경로를 Konva Path로 표시한다.
- ResizeObserver로 컨테이너 너비를 측정해 Stage 크기와 배율을 함께 갱신한다. KaTeX 수식은 HTML 오버레이에 렌더링한다. GSAP 업데이트와 리사이즈 때 기준점의 절대 좌표에 맞춰 라벨을 이동하고, 작은 화면에서는 글자 크기 하한과 배치 충돌을 점검한다.
- 도형 좌표를 바꾸면 약속된 기하 조건을 매번 다시 계산한다. GSAP은 재생 상태와 보간을 담당한다. 드래그를 시작하면 재생을 멈추고 동일한 모델을 갱신한다.
- 도형에 재생·일시정지·초기화 및 키보드로 조작할 수 있는 컨트롤을 제공한다. 동작 줄이기 설정에서는 정적 단계 전환을 제공한다. 설명과 계산 결과는 캔버스 밖의 HTML에서도 읽을 수 있게 한다.
- React가 장면을 내릴 때 타임라인, 옵저버, 이벤트를 해제한다. 수식 출력과 접근성을 검증한다.

| 우선 시범 장면 | 조작과 확인 |
| --- | --- |
| T6 맞꼭지각 | 한 직선을 회전시키고 양쪽 각을 비교한다. |
| T11–T12 부채꼴 | 반지름과 중심각을 조정해 호의 길이와 넓이 변화를 확인한다. |
| T30 피타고라스 정리 | 직각을 유지하며 두 변을 조정하고 각 변 위 정사각형의 넓이를 비교한다. |
| T44–T46 원주각 | 호의 끝점을 고정하고 꼭짓점을 반대편 호에서 이동해 각이 유지되는 것을 확인한다. |

후속 장면 후보는 합동, 삼각형의 외심·내심·무게중심, 닮음, 이차함수, 부피다. 시범 장면으로 조작과 수식 표현을 검증한 뒤 항목별 필요성을 판단한다.

## 단계별 작업 지침

| 단계 | 산출물과 완료 기준 | 커밋 예시 |
| --- | --- | --- |
| 0. 사전 검토 | 원본·가이드·배포 참조 파일을 확인하고 범위 및 미확정 사항을 문서화 | `docs: plan middle school math web app` |
| 1. 기반 | React 앱, 콘텐츠 스키마, 학년·단원 탐색, 검색, 대표 수식. 개발 서버와 프로덕션 빌드 확인 | `feat: scaffold math learning site` |
| 2. 콘텐츠 | 84개 항목과 원본 쪽을 매핑하고 표·수식·기하 조건을 대조. ID 누락·중복 검사 | `feat: add definitions and theorems` |
| 3. 도형 | 공통 도형 컴포넌트와 시범 4종. 수학적 불변 조건, 터치, 키보드, 리사이즈, 재생 복귀 검증 | `feat: add interactive geometry lessons` |
| 4. 배포 준비 | Containerfile, 컨테이너 설정, Quadlet 또는 사용자 서비스, 프록시 설정 예시와 롤백 문서. 컨테이너 빌드 및 /math/ 직접 접근 확인 | `ops: prepare Raspberry Pi deployment` |
| 5. 실제 배포 | 사용자 요청 후 Pi 설치·재시작·기존 서비스 회귀 및 롤백 경로 검증 | `docs: record Raspberry Pi deployment` |

각 단계가 끝나면 한국 날짜로 `doc/work/YYYY-MM-DD-NN.md`를 작성한다. 같은 날짜에 여러 단계가 끝나면 순번을 늘린다. 완료 범위, 변경 파일, 검증 명령과 결과, 남은 이슈를 기록하고 단계 변경분과 함께 커밋한다. 커밋 전에 diff를 검토하고, 커밋 해시는 다음 기록이나 최종 보고에 남긴다.

## 구현과 배포 전에 확인할 사항

- **제품 범위 기본값**은 계정 없는 열람·검색과 시범 애니메이션 4종이다. 관리자 편집, 사용자별 진도, 추가 도형은 필요 시 범위를 정한다.
- **콘텐츠 품질**은 원본의 수식과 도판 대조, 기하 조건 검토, 한국어 검색 및 수식·표의 모바일 가독성을 기준으로 확인한다.
- **운영 환경**은 Pi의 OS 및 아키텍처, Podman 버전, Quadlet 지원, 충돌 없는 포트, 배포 계정과 기존 Nginx 구성을 확인해야 확정할 수 있다. LAN 공개를 기본안으로 두며 외부 공개는 별도 결정한다.
- **커밋 환경**은 정상 Git 저장소와 쓰기 가능한 Git 메타데이터가 필요하다. 현재 작업 경로의 .git은 비어 있고 초기화 시 읽기 전용 오류가 발생했다. 독립적인 저장소에서 만든 이력 번들을 제공할 수 있다.

## 모듈과 컴포넌트 작성 지침

파일은 책임 단위로 나눈다. 학년별 학습 데이터, 탐색과 상세 화면, 수식 렌더러, 공통 도형 캔버스·조작 컨트롤, 장면별 기하 계산과 표현, 배포 설정을 각각 독립된 파일로 유지한다. 두 장면 이상에서 쓰는 계산과 UI는 공통 모듈로 재사용하고, 한 곳에서만 쓰는 간단한 동작은 해당 모듈 가까이에 둔다. 각 장면은 입력값과 출력 도형이 분명해야 하며, 공통 조작 방식은 장면을 추가해도 그대로 쓸 수 있어야 한다.
