# 세로 연속 보기 및 스크롤 메뉴 운영 배포

2026-11-25 (Asia/Seoul), 요청에 따라 현재 작업 소스를 별도 릴리스 디렉터리로 전송하고 Raspberry Pi ARM64에서 Containerfile로 빌드했다. TypeScript 검사와 Vite 빌드가 통과했다.

전체/학년/검색 결과의 모든 항목을 세로로 표시하고, 메뉴 클릭 시 해당 항목으로 이동한다. 스크롤 위치에 따라 메뉴를 활성화하고 메뉴 내부 스크롤도 맞춘다. 데스크톱 사이드바는 sticky로 유지한다. 각 항목의 제목 ID를 고유하게 부여했다.

운영 이미지: localhost/math-web:scroll-20261125
이미지 ID: dcc1399776a6320105e6f2d9859c79c94a90c8a559e16f58e0c08d0772d36080
롤백 이미지: localhost/math-web:rollback-before-scroll-20261125

release 태그를 새 이미지로 지정하고 math-web.service를 재시작했다. 최초 확인 시 시작 직후 연결 초기화로 자동 복구 후, 연결 오류 재시도를 적용하여 재배포했고 healthz가 ok, 서비스가 active임을 확인했다.

공개 HTTPS /mid-math/ HTML이 새 번들 index-AoiVAIfV.js와 index-fF25yR8y.css를 참조하고 두 자산이 200으로 응답함을 확인했다. 기존 / 및 /hamonica/도 배포 전후 200이다. 브라우저의 실제 스크롤 동작은 이번 배포 검증에서 확인하지 않았다.

롤백: Pi에서 `podman tag localhost/math-web:rollback-before-scroll-20261125 localhost/math-web:release` 후 `systemctl --user restart math-web.service`.
