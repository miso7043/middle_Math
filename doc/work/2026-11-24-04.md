# 소인수분해 애니메이션

사용자 참고 그림에 맞춰 D1과 T1에 60 → (2, 30) → (2, 2, 15) → (2, 2, 3, 5) 나무를 추가했다. 각 자식은 부모 위치에서 출발해 연결선과 함께 천천히 펼쳐진다. 소수는 빨간색, 합성수는 파란색으로 구분한다. 각 단계의 식은 캔버스 밖에서도 제공한다.

이 장면의 재생 시간을 18초로 설정하고 완료 후 재생은 처음부터 진행하도록 했다. 기존 장면의 기본 재생 시간은 유지한다. 일시정지, 초기화, 진행 슬라이더 및 동작 줄이기 설정은 공통 재생 기능을 사용한다.

검증: git diff --check 통과. 로컬 Node 실행 환경 문제로 대상 Pi의 ARM 컨테이너에서 npm run build(TypeScript 검사 포함)가 통과했다. 서비스 재시작 후 healthz 및 공개 HTTPS HTML 응답이 정상이며 새 JS 번들 경로가 반영되었다. 이미지 ID: 7cc48d9cfa17991eba57da4c8dda72f01ac8f7879f5eb0cd13dde13581f2c449.
