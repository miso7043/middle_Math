# 작업 완료 절차 지침 추가

2026-11-26 (Asia/Seoul)

## 변경 내용

- 루트 `AGENTS.md`에 작업 완료 절차를 추가했다.
- 작업 후 오늘자 문서 기록, 해당 변경 커밋, 배포 여부 확인 순서를 명시했다.
- 사용자가 배포를 요청하면 배포와 결과 검증까지 수행하고, 배포 기록도 커밋하도록 했다.
- 무관한 기존 변경은 커밋에 포함하지 않도록 했다.

## 검증 및 남은 사항

- 지침 및 문서 내용을 확인했다. 문서만 변경하여 빌드 검사는 생략했다.
- 직전 애니메이션 변경은 타입 검사와 Vite 프로덕션 빌드가 통과했다. 화면 진입 자동 재생, 화면 이탈 초기화, 5초 이내 종료, 재생·초기화 버튼 및 분해 진행 UI 제거를 구현했다.
- 저장소에는 이번 지침 변경 이전부터 여러 미커밋 변경이 있다. 이번 커밋에는 지침과 이 작업 문서만 포함한다.
- 배포는 사용자 요청 대기 상태다.

## 애니메이션 배포 준비

사용자가 배포를 요청했다. 현재 앱 소스를 타입 검사와 Vite 빌드로 재검증했으며 모두 통과했다. 배포 대상은 현재 `src/`와 `/mid-math/` 기준 Vite 설정이다. 이전부터 작업 중이던 앱 변경도 현재 배포 소스에 포함되므로 함께 커밋하여 배포 소스를 재현할 수 있게 한다. 기존 배포 문서 및 프록시 설정 변경은 이번 앱 배포 커밋에 포함하지 않는다.

기존 서비스는 `math-web.service`, 운영 이미지 태그는 `localhost/math-web:release`, 기존 이미지 ID는 `dcc1399776a6`임을 원격에서 확인했다. 기존 프록시는 변경하지 않고 앱 이미지만 교체한다.
