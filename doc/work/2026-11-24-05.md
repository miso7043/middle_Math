# 최대공약수와 최소공배수 정의 분리

기존 D2를 최대공약수로 수정하고 바로 다음에 최소공배수 D2B를 추가했다. 기존 항목 번호와 D2 링크는 유지한다. 각각 공약수·공배수의 뜻과 최대·최소 조건을 설명하고, 12와 18의 약수 또는 양의 배수를 나열하여 최대공약수 6, 최소공배수 36을 찾는 예를 추가했다.

항목 수가 늘어남에 따라 화면의 개념 수는 lessons.length를 사용하도록 수정하고 README의 정의 수를 36개로 갱신했다. JSON ID 중복 검사와 git diff --check가 통과했다. Pi 컨테이너의 TypeScript 검사 및 정적 빌드가 통과했고 앱을 재시작했다. 공개 HTTPS HTML과 새 JavaScript 응답이 200이며 두 예제와 새 항목 ID가 포함되었음을 확인했다.
