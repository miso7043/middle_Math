# /mid-math/ 배포 진행

2026-11-24 (Asia/Seoul).

사용자 요청 주소는 https://rp-yoon.duckdns.org/mid-math/ 이다. Vite base, Nginx 경로, README와 배포 안내를 변경했다. 기존 HTTPS 설정의 백업, 검사, 오류 시 복구를 포함한 `deploy/enable-mid-math.sh`를 추가했다.

Pi `yoon-pi5.local`의 `~/middle-math`에 소스를 전송했다. ARM64 Podman 빌드에서 TypeScript 검사와 Vite 빌드가 통과했다. 이미지 ID는 `e68e49bdab30e6e7791e8cfa20cec661576817830df4f0895755cbdd56475bbb`이다. 사용자 Quadlet `math-web.service`를 설치하고 실행했으며 linger가 활성화되어 있다. 루프백 `127.0.0.1:8040`의 healthz와 HTML 응답을 확인했다. HTML의 자산 경로는 `/mid-math/assets/`이다.

외부 주소 연결은 아직 완료되지 않았다. `sudo -n nginx -T`가 관리자 인증 필요 오류를 반환했다. 사용자에게 문서의 `ssh -t ... sudo bash ...` 명령 실행을 안내해야 한다. 현재 외부 `/mid-math/`는 404이며 기존 루트와 `/hamonica/`는 각각 HTTPS 200이다. Nginx 반영 후 외부 HTML 및 자산과 기존 경로를 재검증해야 한다.

로컬 npm은 snap-confine 오류로 실행되지 않아 실제 대상 Pi의 컨테이너 빌드로 검증했다. npm ci는 의존성 취약점 3개를 보고했으며 이번 배포에서 의존성 버전은 변경하지 않았다.
