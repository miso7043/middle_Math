# 최대공약수 예제 애니메이션

2026-11-26 (Asia/Seoul)

## 변경 내용

- 최대공약수 D2의 예제와 풀이 아래에 애니메이션을 추가했다.
- 12의 약수, 18의 약수가 순서대로 나타나고 두 줄의 공약수 1, 2, 3, 6에 SVG 동그라미가 그려진다.
- 공약수 안내, `1 < 2 < 3 < 6`, 최대공약수는 6이라는 결론이 순서대로 나타난다. 전체 시간은 약 4.4초다.
- 화면 진입 시 자동 재생하고 화면 이탈 시 초기화한다. 작은 화면에서는 약수가 줄바꿈되며, 동작 줄이기 설정에서는 모든 내용을 즉시 표시한다.

## 검증 결과

- `npm run build` 성공: TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- `git diff --check` 통과.
- D2 예제의 약수와 공약수가 구현 내용과 일치하는 것을 확인했다.

## 남은 사항

- 브라우저에서 실제 애니메이션과 모바일 화면 육안 검증은 수행하지 않았다.
- 배포는 사용자 확인 후 진행한다.
