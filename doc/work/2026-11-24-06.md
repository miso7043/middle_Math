# 전체 항목 예제와 풀이

전체 85개 항목(중1 26개, 중2 31개, 중3 28개)에 문제 상황과 단계별 풀이를 갖춘 예제를 제공했다. 새 `src/content/examples.json`에 항목 ID별로 관리하며, 최대공약수·최소공배수의 기존 예는 문구를 유지해 공통 예제 영역으로 옮겼다. 공식이나 조건이 여러 개인 항목은 각각을 설명하는 예를 포함한다.

`Lesson` 데이터에 examples를 연결하고 검색 대상에도 추가했다. 상세 화면은 '예제와 풀이' 제목, 문제, 순서 있는 풀이로 표시한다. 정의·정리 출처 표시를 구분하고 피타고라스 정리의 역 본문의 c2 오타를 c²로 수정했다.

검증: 85개 ID와 예제 ID의 정확한 일치, ID 중복 없음, 모든 예제에 문제와 두 단계 이상의 설명이 있음을 확인했다. 산술·방정식·부채꼴·피타고라스·통계의 수치 계산을 별도로 검산했고 git diff --check가 통과했다. Pi의 ARM64 Podman 컨테이너에서 npm run build(TypeScript 검사 포함)가 통과했고 math-web.service를 재시작했다.

브라우저 UI 검증은 browser access host unavailable로 수행하지 못했다. 공개 HTTPS의 HTML, JavaScript와 CSS가 정상 응답하고 최신 번들에 85개 예제의 문제 문장, 예제 제목, 스타일이 모두 포함되었음을 확인했다. 기존 루트와 /hamonica/도 200이다. 배포 이미지: 78974a9aa794ef24e4d097180373aebd17342de7a2a64d1dd281a33287d3c757.
